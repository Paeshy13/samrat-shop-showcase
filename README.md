# Samrat Supermarket Nyeri

Ever heard of or do you know about Samrat Supermarket in Nyeri? I need a frontend interactive website for the supermarket. The site should only show minimal data, explaining what the supermarket does, what they sell and show the location. It should also give the option to change the background to light, dark and system default(This should follow the system's lighting). Also put their contact information. Background should be blue and orange. Use the photo uploaded as their logo
